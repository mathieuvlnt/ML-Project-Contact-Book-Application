# ML-Project-Contact-Book-Application

We started from a business-oriented approach based on the requirements of the assignment. 
The idea was to access a client directory within a company. We therefore developed a contact book that can be used directly through the interface.
The basic features are included: adding, deleting, or editing a contact, as well as displaying an overview of the book or searching for a specific contact.

However, these simple options seemed too limited for the model we wanted to build. 
This is why we decided to add each client's job title and provide statistics based on it, to improve visibility within the book, with clients naturally sorted alphabetically. 
For the same purpose, we added the ability to export the book in CSV format to make database creation easier.

Additionally, we included password verification to access the interface, ensuring that the client directory remains secure since it contains personal information. 
Finally, for greater consistency and reliability, we added validation for phone number and email address formats, making it impossible to add contact without valid information.
